Process

Claude Code との開発の流れ

01

アイデアを言葉にする

「ぷよぷよみたいなゲームをかわいいクマで作りたい」と日本語で入力したら、Claude Code はすぐに動く Python コードを返してくれました。 ゲーム開発の知識ゼロでも、アイデアを言葉にするだけで雛形が完成する体験に驚きました。

02

対話しながら改善する

「もっとキャラをぷるぷる動かしたい」と伝えると、アニメーション処理がすぐに追加されました。 「連鎖のエフェクトを派手にしたい」「スコア表示の位置を変えたい」など、感覚的なフィードバックをそのまま伝えるだけで仕様が固まっていきました。

03

ゲームとして完成させる

スコア・チェーン・NEXT表示・キーボード操作など、遊べるレベルまで機能を積み上げました。 「AIがコードを書き、自分がディレクションする」という新しい開発スタイルを、ゲームを通じて体験できました。
